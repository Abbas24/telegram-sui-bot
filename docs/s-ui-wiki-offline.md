# S-UI Wiki Offline Reference

Snapshot of https://github.com/alireza0/s-ui/wiki/

The S-UI project is a web panel for sing-box. It provides infrastructure for managing and serving configuration files to connected clients.

## Subscriptions
This category describes the process regarding "how clients fetch their configuration from the panel."
- **Subscription Service**: Provides data on "subscription URLs, the three formats, response headers and the settings that shape them."
- **Subscription JSON Template**: Lists the "structure and supported keys of the sing-box (JSON) subscription template, with worked examples."
- **Subscription Clash Template**: Explains requirements for "the Clash.Meta (YAML) template, proxy groups and filters."

## Automation
This grouping concerns programmatic interactions.
- **API Documentation**: Details the "token-authenticated REST API (`/apiv2`), endpoint by endpoint."
- **Configuration Objects**: Defines the "shape of the objects you read and write through the API."
- **Settings Reference**: Explains "every panel setting, its default and what it affects."

## Getting Started
Operational requirements for setup can be found in the main repository: "Installation, ports and default credentials are covered in the README."
